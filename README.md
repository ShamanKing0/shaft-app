# 🚛 شفط — منصة طلب شاحنات الصرف الصحي

تطبيق ويب (PWA-ready) يربط العملاء الذين يحتاجون شاحنة شفط صرف صحي بأصحاب الشاحنات القريبين منهم. مبني بالكامل لخدمة السودان: واجهة عربية RTL، بسيطة جدًا، Mobile First.

## المكدس التقني (Stack)

- **Backend:** Node.js + Express 5
- **Database:** SQLite (عبر better-sqlite3) — ملف واحد، لا حاجة لخادم قاعدة بيانات منفصل
- **Frontend:** HTML + CSS + JavaScript خالص (SPA بدون إطار عمل، بدون خطوة بناء Build) — يعمل من نفس خادم Express
- **Auth:** رقم الهاتف + رمز تحقق (OTP وهمي في وضع التطوير: **0000** دائمًا صالح)

## التشغيل محليًا

```bash
npm install
npm run seed      # إدخال بيانات تجريبية (عملاء/سائقين/شاحنات/طلبات)
npm start
```

افتح المتصفح على: `http://localhost:3000`

### حسابات تجريبية جاهزة (رمز التحقق دائمًا 0000)

| الدور | رقم الهاتف |
|---|---|
| عميل | 0911111111 |
| سائق (شاحنته موثّقة وجاهزة) | 0922222221 |
| مدير النظام | 0900000000 |

## كيف يعمل نظام المطابقة؟

عند إرسال طلب، يبحث الخادم عن السائقين "المتاحين والموثّقين" ضمن نطاق **5 كم**، وإن لم يجد أحدًا يوسّع البحث إلى **10 كم** ثم **20 كم**. قبول الطلب عملية **atomic** في قاعدة البيانات (`UPDATE ... WHERE status='searching'`) بحيث يستحيل أن يقبل سائقان نفس الطلب في نفس اللحظة.

## الأمان

- كل مسار محمي بالتحقق من الهوية (Bearer token) والدور (customer/driver/admin).
- العميل لا يمكنه الوصول لمسارات السائق أو الإدارة، والعكس صحيح.
- كل المدخلات يتم التحقق منها في الخادم قبل الحفظ.

## النشر (Deployment)

المشروع جاهز للنشر على أي منصة تدعم Node.js (Railway, Render, Fly.io, VPS عادي):

1. ارفع المشروع إلى مستودع GitHub.
2. على **Railway**: أنشئ مشروعًا جديدًا → "Deploy from GitHub repo" → اختر المستودع. سيكتشف Railway تلقائيًا أنه مشروع Node.js وسيشغّل `npm install` ثم `npm start`.
3. أضف متغير البيئة `PORT` إذا لزم (Railway يوفره تلقائيًا).
4. بعد أول نشر، شغّل مرة واحدة: `npm run seed` من تبويب "Shell" في Railway لإدخال بيانات تجريبية (اختياري).

> ملاحظة: قاعدة البيانات SQLite هنا كملف محلي — إذا نشرت على منصة بدون تخزين دائم (Ephemeral filesystem) ستُفقد البيانات عند كل إعادة نشر. لإنتاج حقيقي طويل الأمد، يُنصح بالترقية لاحقًا إلى PostgreSQL (Railway يوفره كإضافة بضغطة زر) أو تفعيل Volume دائم لملف SQLite.

## ما التالي (خارج نطاق MVP الحالي عمدًا)

- دفع إلكتروني / محفظة / اشتراكات
- خرائط تفاعلية كاملة (حاليًا: GPS + إدخال عنوان يدوي + رابط Google Maps للاتجاهات)
- إشعارات Push حقيقية (حاليًا: تحديث الحالة عبر Polling كل 5 ثوانٍ)
- رفع صور الشاحنة والمستندات (الحقول جاهزة في قاعدة البيانات `photo_url`, `document_url` لإضافتها لاحقًا)
- OTP حقيقي عبر مزود SMS (حاليًا رمز ثابت 0000 للتطوير)
